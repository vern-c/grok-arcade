# Grok Arcade

An 80's-inspired retro arcade lobby for six Grok-built games:

| Cabinet | Vibe |
|---------|------|
| **Grok-ris** | Stack blocks or die trying. Magic bag included. |
| **Grok-aga** | Move AND shoot like the multitasker your parents never believed in. |
| **Grok-Man** | The G that chomps back. Eyeless spirits, zero lawyers. |
| **Grok-out** | Paddle. Ball. Bricks with commitment issues. |
| **Grok-roids** | Thrust. Spin. Panic. Repeat. |
| **Grok-ger** | Cross the road. Touch grass (pixel grass). |

**Play:** [vern-c.github.io/grok-arcade](https://vern-c.github.io/grok-arcade/)

## Hub features
- Pure retro CRT / neon aesthetic (Press Start 2P, scanlines, glows)
- Static start-screen cabinet previews
- Insert Coin mechanic + credit counter (with classic coin jingle)
- Direct links to each game on GitHub Pages
- Fully self-contained `index.html`

## Run locally
```bash
open index.html
```
